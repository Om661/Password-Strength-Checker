# 🔐 Simple Password Strength Checker

A beginner-level Python project that checks the strength of a password based on basic cybersecurity principles.

## Features
- Checks for length, uppercase/lowercase, numbers, and symbols
- Gives feedback and suggestions to improve password strength

## Usage
1. Clone this repo  
   `git clone https://github.com/yourusername/password-strength-checker.git`
2. Run the script  
   `python password_checker.py`
3. Enter your password to test its strength.
